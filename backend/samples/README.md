# Demo samples

- `synthetic_suspicious.exe` - safe to commit. A hand-crafted, inert PE generated by
  `backend/tests/make_synthetic_pe.py` (pure Python, no compiler needed, regenerate any time
  with `python tests/make_synthetic_pe.py`). Imports process-injection APIs without ever
  calling them, and embeds decoy IOC/lure strings plus the EICAR test string.

- `clean_sample.exe` - **not committed** (see `.gitignore`). This is a real Microsoft system
  binary (a copy of `notepad.exe`), used locally to prove the pipeline doesn't false-positive on
  legitimate software. Redistributing it isn't ours to do. Every teammate should create their
  own local copy before running the tests or demo:

  ```powershell
  Copy-Item "C:\Windows\System32\notepad.exe" "backend\samples\clean_sample.exe"
  ```

  Any legitimate, non-sensitive Windows executable works equally well for this check - it
  doesn't have to be notepad.exe specifically.

- `make_test_sample.c` - source for a compiled+packed sample, for teams with MinGW/MSVC
  available who want a real (still harmless) binary for the entropy/UPX part of the demo. See
  the build commands in the file's header comment.
